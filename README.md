## 📂 源码工程

项目按客户端、平台服务、子游戏、Web 和界面资源组织。下面为源码项目内的相对目录，便于了解工程结构。

```text
HY/
├── client/
│   ├── client/
│   │   ├── client/          大厅相关代码
│   │   └── game/            Lua 游戏模块
│   └── frameworks/          客户端引擎与平台工程
├── Server/
│   └── 子游戏/              游戏服务与相关组件
├── WebCode/                 Web 前台与管理后台
├── DB/                      数据库相关文件
├── UI/                      界面与资源工程
└── UI_Game/                 子游戏界面工程
```
